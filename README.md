# Filmax

**A streaming app for Android TV.** Filmax is an unofficial kino.watch client with a
browsable catalog, episode-level watch progress, flexible playback controls, voice
search, personal collections, and automatic updates.

## Features

- **Continue watching:** watch progress is synchronized with kino.watch down to the
  episode, and playback can resume where you stopped.
- **Player:** choose video quality, audio track, subtitles, and playback speed; browse
  seasons and episodes without leaving the player.
- **Catalog and search:** browse by type or genre, sort results, apply filters, and use
  text or voice search.
- **Title details:** view Kinopoisk and IMDb ratings, cast, director filmography,
  trailers, seasons, and episodes.
- **Watching:** quickly access titles in progress and your viewing history.
- **Collections:** manage the Watch Later list and personal bookmark folders.
- **Automatic updates:** download and install new versions directly from the app.
- **Offline fallback:** previously cached content remains available when the service
  cannot be reached.

## Installation

1. Download `filmax-X.Y.Z.apk` from the
   [latest release](https://github.com/kazhuravlev/filmax/releases/latest).
2. Install the APK on an Android TV or Google TV device.
3. Sign in with your kino.watch account using the activation code shown by the app.

Filmax will notify you when a new version is available and can install the update
without an external app store.
